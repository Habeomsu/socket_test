# 간단한 소켓 프로젝트

이 리포지토리는 다양한 소켓 구현을 위한 프로젝트들을 포함하고 있습니다. 각 프로젝트는 기본 소켓 구현에 추가적인 기능을 제공합니다.

## 프로젝트 목록

### 1. socket_1

- **설명**: 기본 소켓 구현
- **기능**: 
  - 기본적인 소켓 통신 기능 제공
  - 클라이언트와 서버 간의 메시지 송수신
  - WebSocketHandler를 통해 웹소켓 연결, 양방향 통신, 웹소켓 연결 종료, 에러처리를 구현

### 2. socket_2

- **설명**: 기본 소켓 + STOMP 프로토콜
- **기능**:
  - 기본 소켓 통신 기능 제공
  - STOMP 프로토콜을 추가하여 메시징 기능 향상
  - 클라이언트와 서버 간의 비동기 메시지 전송 지원

### 3. socket_3

- **설명**: 기본 소켓 + STOMP + RabbitMQ
- **기능**:
  - 기본 소켓 통신 기능 제공
  - STOMP 프로토콜을 사용하여 메시징 기능 향상
  - RabbitMQ를 사용하여 메시지 브로커 기능 추가
  - 분산 시스템에서의 안정적인 메시지 전송 및 처리를 지원

## 기술 스택

- Java
- Spring Boot
- WebSocket
- STOMP
- RabbitMQ
